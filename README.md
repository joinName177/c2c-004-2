# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高与承重配置
- 物品清单、类别、尺寸、重量、优先级和必带标记
- 确定性三维长方体装箱、旋转与碰撞检测
- 三套方案对比和双投影视图联动
- 手动装箱工作台：俯视图拖动移动、侧视图调整高度、旋转查看风险，移动先预览，越界/相交/底面无完整支撑不能提交
- 位置锁定：重新装箱只安排未锁定物品，锁定项绝不挪动
- 箱体或锁定物品尺寸修改导致位置失效时，保留上次有效摆放并列出冲突，可解除锁定或取消修改
- 调整可撤销，确认后位置、风险和打印清单一起更新，锁定安排保存在本地
- 超重、空间紧张、尺寸越界、必需品遗漏、易碎品受压和重心风险
- localStorage 本地保存与打印清单（含每件物品的位置与朝向）

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

## 手动装箱工作台

从任一自动方案载入后，可在俯视图拖动调整水平位置、侧视图拖动调整高度，或用微调按钮与坐标输入精确定位；旋转会即时刷新两个视图和风险预览。每次移动先显示预览：越界、与其他物品相交或底面没有完整支撑时无法提交。确认后位置、风险和打印清单同时更新，撤销可完整回到调整前。

锁定满意的物品后，“重新装箱”只安排未锁定的物品，锁定项作为固定障碍绝不移动。若修改箱体或锁定物品的尺寸导致原位置失效，系统保留上次有效摆放并列出冲突，等待解除锁定（物品回到待装）或取消修改（恢复原尺寸）。手动布局与锁定状态保存在 localStorage，关闭页面再打开仍会恢复。

## 开发与测试

```bash
npm install
npm run dev
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

docker compose up --build
